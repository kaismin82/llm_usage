# r2 - Lead verification from official docs (webfetch, 2026-10-01)

## Poe (official: https://creator.poe.com/docs/resources/usage-api)
- VERDICT: CONFIRMED | GET https://api.poe.com/usage/current_balance, `Authorization: Bearer <key>` (key from https://poe.com/api/keys), response `{ "current_point_balance": 1500 }` (integer; "plan points and add-on points" combined per https://creator.poe.com/api-reference/getCurrentBalance). No query params.
- VERDICT: CONFIRMED | GET https://api.poe.com/usage/points_history, query `limit` (default 20, max 100), `starting_after` (= `query_id` of last entry). Newest first. Data up to 30 days old.
- Response: `{ has_more: bool, length: int, data: [ { bot_name, creation_time (Unix timestamp in MICROSECONDS), query_id, cost_usd (string), cost_points (int), cost_breakdown_in_points (object of strings), usage_type ("Chat" | "API" | "Canvas App"), chat_name?, canvas_tab_name?, api_key_name? } ] }`.
- Error: `{ "error": { "message": "Incorrect API key provided...", "type": "authentication_error", "code": "invalid_api_key" } }` (401).
- Consequence: monthly (calendar month up to 31 days) cannot be fully derived from a 30-day window -> extension must accumulate history locally (dedupe by query_id). Poe usage history includes Chat (subscription) usage too, not only API.

## OpenRouter (official: https://openrouter.ai/docs/api-reference/limits)
- VERDICT: CONFIRMED | GET https://openrouter.ai/api/v1/key, Bearer key. `data.{label, limit (null=unlimited), limit_reset (reset type or null), limit_remaining, include_byok_in_limit, usage (all time), usage_daily (current UTC day), usage_weekly (current UTC week, starting Monday), usage_monthly (current UTC month), byok_usage, byok_usage_daily, byok_usage_weekly, byok_usage_monthly, is_free_tier, free_model_daily_requests{used,limit,remaining}}`; `rate_limit` deprecated. Units = credits (USD).
- VERDICT: CONFIRMED | GET https://openrouter.ai/api/v1/activity (https://openrouter.ai/docs/api/api-reference/analytics/get-user-activity-grouped-by-endpoint.md): Management key required (403 "Only management keys can perform this operation" otherwise), last 30 completed UTC days, optional `date=YYYY-MM-DD`, `api_key_hash`, `user_id`, `workspace_id`, `group_by=workspace`. Items: `{date, model, model_permaslug, endpoint_id, provider_name, usage (USD), byok_usage_inference, requests, prompt_tokens, completion_tokens, reasoning_tokens}`.
- Consequence: per-key daily/weekly/monthly comes free from /key (UTC boundaries, Monday week start). Account-wide totals need a management key + /activity (excludes today, since only completed days).

- VERDICT: CONFIRMED | GET https://openrouter.ai/api/v1/keys (official: https://openrouter.ai/docs/api/api-reference/api-keys/list-api-keys.md) - Management key required. Query: include_disabled ('true'/'false'), offset (int), workspace_id (uuid; default = default workspace). Each item: {hash, name, label, disabled, limit, limit_remaining, limit_reset, include_byok_in_limit, usage, usage_daily (current UTC day), usage_weekly (current UTC week Monday-Sunday), usage_monthly (current UTC month), byok_usage*, created_at, updated_at, expires_at, external_user, creator_user_id, workspace_id}. USD.
- Consequence: account-wide today/week/month INCLUDING today = sum over /keys items (include_disabled=true, paginate offset, per workspace). /activity is only for per-model/per-day history of completed days.
